# Acknowledgements

KnowledgeRail is independently designed and implemented. It is not affiliated with or endorsed by Andrej Karpathy.

The project's earliest knowledge-management direction was inspired in part by Andrej Karpathy's April 2026 [`llm-wiki.md` idea file](https://gist.github.com/karpathy/442a6bf555914893e9891c11519de94f), especially the idea that an LLM can maintain a durable Markdown knowledge base whose synthesis compounds over time.

That idea is an origin point, not the present product definition. KnowledgeRail developed into a separate MCP 2.0 agent-memory system that adds guided workflows, bounded hybrid retrieval, explicit coverage and unknowns, Evidence IR, source-completeness gates, deterministic code evidence, graph and semantic indexes, legacy migration, and contract-driven Markdown authoring and review.

This acknowledgement credits conceptual inspiration. It does not imply that Andrej Karpathy authored, reviewed, sponsored, or endorsed KnowledgeRail.
